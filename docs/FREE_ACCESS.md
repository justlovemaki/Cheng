# LexiHalo 独立版改造说明

此目录是由原上游扩展构建产物改造而来的 **LexiHalo** 独立版，不包含原始前端或后端源码。

## 品牌信息

- 新名称：`LexiHalo - AI 翻译与双语字幕`
- 扩展图标、页面 Logo、弹窗品牌和全部本地化名称已替换为 LexiHalo。
- 当前版本号：`8.3.0`
- 用户可见名称中已清除旧品牌；源码中保留的小写 `trancy-*` CSS 类、事件名、存储键、引擎类型和历史域名仅用于兼容现有构建结构，不作为品牌展示。

## 已完成的客户端改造

- 登录用户在后台、阅读器和视频模块中统一按 `premium: true` 处理。
- 后台返回给内容脚本的状态统一带有本地免费权限。
- 会员过期事件不再重置主题、语音或 TTS 设置。
- 阅读器和视频高级主题已开放。
- 自定义语音及 Azure 阅读语音已取消会员判断。
- 视频练习入口和“下一句”的时长限制已取消。
- 字幕点击处理器、单词卡加载器、网页选词和“精准释义”入口均已取消登录要求。
- 未登录时，“精准释义”会使用当前词典结果作为本地回退，不再跳转登录；云端释义失败或返回 401 时也只显示重试，不显示登录拦截。
- AI 单词详解、自动解释、语法、视频总结和 AI 字幕的客户端会员判断已移除；独立版中原上游云端实现会被停用。
- 视频播放器内嵌工具栏已移除仍依赖原上游云端的 AI 字幕转录、AI 总结、收藏视频和学习中心入口，以及不可用的托管高级引擎；保留字幕开关、语言、BYOK/免费引擎、显示模式、样式、键盘控制、字幕下载和快捷键。
- 点击字幕单词打开的 AI 详解已改用本地配置的 BYOK 模型生成，保留词性、释义、例句、词形、词源、短语和同义词等详情结构；详情页同时显示标记为 `Web Dictionary` 的基础网页词典结果，并固定提供美式/英式发音切换。英语动词会要求模型返回原形、第三人称单数、现在分词、过去式、过去分词及现在/过去/将来进行时和完成进行时等完整形式。
- AI 详解侧栏及页面选词小弹窗已精简，移除无效的“收藏单词 / 已掌握”云端操作；保留并恢复 Oxford、Collins、Longman、Youdao 外部词典入口。页面选词小弹窗明确标注基础结果为 `Web Dictionary`，“精准释义”则独立调用本地 BYOK 模型按句子上下文生成，不再回退并重复显示 Web 词典结果。
- 插件侧边栏已精简为关闭、设置、沉浸式翻译和快速翻译四个侧面按钮；移除词库、PDF、学习中心、App 和推广入口。点击扩展图标现在始终打开设置首页，不再因学习语言为英语而默认进入生词本；生词本相关路由也已移除。沉浸式翻译和快速翻译按钮执行后不再自动关闭侧边栏。
- 快速翻译改用独立的 `xt-card` 容器，并在侧栏关闭动画完成后再挂载，避免与 `xt-slider` React 根节点冲突导致 `removeChild` 异常。
- 设置首页已移除账号、Free Access 标识、邮箱验证横幅、词书高亮、教程、反馈和更新日志，并停止首页的 Profile、Meta、Config、通知及词书云端请求；保留 BYOK 引擎和本地功能设置。
- 双语字幕设置的支持网站列表直接读取 `config/media-platforms.json` 权威目录，完整展示 32 个已适配平台（含 Pornhub、新增视频/课程站点及音频/播客站点），新增平台无需手动补写设置页。全部站点使用扩展本地打包的真实品牌图标（保留原有 12 个图标，新增 20 个取自站点官方 favicon/Apple touch icon；来源见 `assets/platform/sources.json`），不依赖外部图标服务；站点卡片使用目录中的 `homepage` 官网地址，在新标签页打开，支持点击图标、名称、外链标识或键盘 Enter（视频号进入 `channels.weixin.qq.com`，小鹅通进入 `www.xiaoe-tech.com`），不再从匹配域名推测官网入口。Reader/Video 两个运行环境的旧版外链拦截器仅放行目录中平台卡片的精确官网地址，其他外链继续拦截。同时说明通用 HTML5 播放器、BYOK 转写、本地助手及登录/DRM 等限制。Bilibili 运行时现在会立即启动按钮、字幕拦截器和字幕容器，不再等待可能错过的 `subtitle.loaded` 事件；检测到新字幕后仅触发刷新。Bilibili 仍要求视频存在可读取的软字幕轨道，画面内烧录字幕无法提取。
- 优化 AI 字幕翻译流程：无需额外开关，当用户选择本地配置的 BYOK AI 引擎（OpenAI、DeepSeek、Claude、Gemini 等）翻译视频字幕时，系统用一次供应商适配器请求同时完成 ASR 保守修复和翻译。请求按字幕字符数使用 2048–8192 动态输出额度、稳定 6 行窗口、最多两个并发，并在播放位置跳转时取消旧代次；当前字幕不再先用 Google 临时回填。双语字幕页分别提供“重新载入当前字幕”和“彻底清除 AI 字幕缓存”，前者保留持久 AI 结果且无需重新下载字幕轨道，后者强制下次重新请求模型。
- 沉浸式翻译增强了无限滚动、虚拟列表和 Shadow DOM 支持：新增空容器会进入观察队列，并在 350ms 与 1200ms 后复查异步填充内容；文本节点更新会延迟复查，进入视口时再执行翻译。动态 DOM 观察器现已在 Bilibili 等所有支持页面启用，并会递归发现、监听和补扫新建的开放 Shadow Root，同时向其中注入翻译样式，因此 Bilibili Web Components 中滚动加载的评论也会进入翻译队列。
- 翻译引擎页面已移除无意义的原上游云端额度余额（原 `1.0000`）和不可用的托管高级引擎分组，只显示免费引擎及本地 BYOK 引擎。
- 字幕单词点击不再受“悬停词典”开关和 lookup 状态限制；即使字幕被渲染成无事件的普通文本，也会由顶层委托点击处理器打开 AI 详解侧栏。
- Trusted Types 兼容逻辑会优先复用页面已有的默认策略，或仅创建 CSP 允许的 `default` 策略，不再尝试创建被 YouTube 等网站 CSP 禁止的自定义策略名。
- 词书切换的客户端会员判断已移除。
- 高级翻译引擎在客户端统一标记为可选，`AIEngineAvailable` 默认开启。
- 新增“沉浸翻译常开”设置页，用于维护沉浸式翻译的 URL/域名规则；支持精确域名、`*.` 子域通配符和路径 `*`，可通过网页右键菜单直接添加/移除当前网站，也可在管理页一键操作、回车添加及逐条删除。修改会实时应用，并在 SPA 地址切换时重新匹配；双语字幕继续使用原有常开设置。
- 新增本地 BYOK 配置页 `byok.html`，支持 Microsoft Translator 官方 Azure API、DeepL Free/Pro，以及 OpenAI、OpenRouter、DeepSeek、Gemini、Claude 和 OpenAI 兼容接口。由于 Edge 匿名翻译 token 端点目前会返回 404，微软翻译采用用户自己的 Azure API Key，不伪装成可用的免密服务。
- 翻译引擎设置入口已改为打开本地 BYOK 页面，不再依赖 `learn.trancy.org/advanced-ai`。
- BYOK 配置保存在 `chrome.storage.local`；引擎列表返回页面时会移除 API Key，真正翻译时仅由后台补回密钥。
- 即使 `/2/translator/engines` 不可用，只要本地配置了 BYOK，扩展仍会返回本地引擎。
- 所有活动代码中的 `openPremium(...)` 调用和 `/setting/premium` 跳转已移除。
- API 返回 403 时不再跳转付费页面。
- 会员标识改为 `Free Access`，账号页不再显示升级入口。
- Premium 路由已从阅读器路由表中移除。
- 修复 `getStateChunks({ exclude: [...] })` 返回键名数组的问题。
- 修复按需状态缺少 `edreader` 时切换字幕语言写入 `areaPhonetic` 崩溃的问题；后台向扩展设置页等无内容脚本的标签页发送消息时会安静跳过，不再产生连接失败和未处理 Promise 错误。

## 8.0.0 独立版改造

- 移除 Manifest 中的 Chrome Web Store 自动更新地址和 `externally_connectable` 本地网页入口。
- 后台统一阻止所有 `trancy.org` 子域和 Google Analytics 请求。
- Google Analytics 埋点函数已改为本地 no-op。
- `api.trancy.org` 常量已替换为不可联网的本地无效扩展地址。
- 安装时不再自动打开用户指南，卸载时不再设置回访 URL。
- 后台、阅读器、视频和弹窗均阻止打开 HTTP/HTTPS 推广及帮助页面。
- 扩展自身 UI 中的外部链接点击会被捕获并取消；视频页面自身链接不受影响。
- 学习中心、帮助、反馈、评论、定价和账号页面不再从扩展打开。
- 移除 Google Fonts 和内置 Google 引擎的远程上游图标依赖。
- 使用本地 `Standalone` 身份，不再要求上游账号登录。
- 本地 BYOK 在没有上游 API 的情况下仍可加载和使用。
- 基础划词/字幕单词查询在上游词典不可用时，会回退到当前 BYOK 或第三方翻译引擎，保证独立版仍可显示结果。

## 已停用的云端功能

以下原本依赖原上游后端的功能在独立版中会返回 `standalone_only`，不会发起网络请求：

- 云端收藏单词、句子和词书同步；
- 原上游云端 AI 单词释义（字幕单词详解已由本地 BYOK 替代）；
- AI 语法和断句；
- AI 总结；
- AI 字幕；
- 原上游托管的高级翻译引擎（本地 BYOK AI 翻译不依赖该额度）；
- 云端 TTS 或其他需要付费供应商的能力。

AI 翻译应使用本地 BYOK。视频站字幕读取、用户主动配置的 BYOK Endpoint，以及保留的第三方翻译服务不属于上游后端依赖。

## 注意

这些修改直接作用于压缩构建文件。重新执行原项目构建会覆盖修改，长期应在原始源码和后端源码中实现相同策略。
