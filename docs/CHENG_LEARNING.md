# 澄 Cheng：视频精读与知识笔记

定位：帮助认真学习外语视频内容的人，看懂内容、理解概念、积累知识。服务研究生、开发者、专业从业者与自主学习者，不限定学科或职业。

## 默认流程：在视频旁边学

点击原右侧吸附栏的「学习控制台」，打开浏览器原生侧边面板 `study.html`，不导航到新标签页。需要 Chrome / Edge 116+ 的 sidePanel API；原扩展图标、设置和视频按钮不改变。

- 自动连接当前网页中的主要播放器；暂停、跳转、译文更新会同步到面板。约每 400ms 读取附近最多 8 行字幕，不轮询整段字幕，也不自动请求 AI。
- 原文和已有译文实时高亮；点击字幕正文或时间跳转，左侧复选框负责选择。可勾选 1–10 句；选择集合独立于当前约 8 行实时窗口，字幕滚走后仍保留，重新出现时恢复勾选，切换视频才清除。点击工具条中的“已选 N 句”可在覆盖浮层查看全部选择、跳回或逐句取消。工具条、选择查看和 AI 表单都不改变字幕区域高度。
- 译文复用现有播放器/扩展字幕。没有译文时可从面板明确点击「启用原有双语字幕」，按原设置的语言和引擎运行；AI 引擎可能收费，不是新增一套自动 AI 翻译。
- 「学习笔记」区别于下方「视频片段 AI 解释」：打开面板即可直接写自己的理解、问题或灵感，不需要先选视频、字幕、网页或资料，也不会自动发送给模型。空编辑器不会制造空白笔记；点「新建」开始下一条。
- 通用笔记不替代原功能。实时双语对照、字幕时间跳转、单句/选中范围重听、所选字幕 AI 解释以及原悬浮栏中的设置、快速翻译、沉浸翻译全部保留。非视频网页仍显示视频模块及不可用原因，切回视频标签后自动恢复，而不是隐藏或删除。
- 出处是可选元数据。网页笔记保存经清理的页面 URL、标题和选文；视频笔记通过资料与片段保存来源 URL 和时间范围。资料库中的每条关联笔记均提供“打开出处页面”，视频笔记另提供“跳到 HH:MM:SS”；Markdown 导出也包含来源链接与时间。可在文章中选中文字后关联网页和选文；没有选文时只记录网页链接。选在密码框、表单或可编辑区域内的文字不会捕获。关联、替换或取消出处都保留原笔记文字。
- 已关联的视频笔记继续播放或切换视频不会自动改绑；关联网页时会再次验证标签页 URL，避免导航竞态串到另一页。保存后可直达资料库该条笔记并定位高亮。无字幕时也能关联视频当前时间点。
- 输入笔记后约 450ms 写入本机；输入同时写本机草稿日志。重开面板会恢复未完成草稿；若与已保存笔记不同，保留原笔记并恢复副本，不静默覆盖。切换视频不会把正在编辑的笔记改绑到其他资料。
- 「解释选中字幕」本身就是明确的发送操作。一次可选 1–10 句，模型还会获得每句附近最多各两句的上下文、问题和匹配术语，不包括个人笔记。预览可选；所选字幕在继续播放时保持不变，切换到另一视频才清除。
- 自动跟随活动网页；切换到资料库或设置等非网页标签时，保留最近的视频连接。原视频发生切换时会验证身份，旧操作不能写到新视频上。
- 独立 `workspace.html` 分为“学习笔记”和“资料与媒体”。侧边面板顶部的“资料与媒体”、普通资料库入口以及 `view=materials` 始终进入资料标签，不再根据是否存在笔记自动切换；只有“查看笔记”“查看引用笔记”或 `view=notes` 进入笔记标签。学习笔记是笔记正文唯一的列表、搜索、编辑和删除入口；资料详情中的“字幕与时间片段”把来源标为“笔记引用”或“独立保存”，显示笔记/截图引用数量与跳转按钮，不重复渲染正文。实时字幕为笔记保存的出处属于自动引用片段；字幕精读中“保存为独立片段”属于用户主动收藏。笔记取消关联或删除后，无其他笔记/截图引用的自动片段会清理，独立片段不会随笔记删除。本地媒体播放、字幕手动导入和批量处理仍在资料与媒体中。

原站没有可读字幕、DRM、封闭播放器或无法获取正确播放时钟时，面板会提示限制，不会假造字幕或自动上传音频。

## 已实现的三个阶段

### 第一阶段：留下知识

- 实时控制台入口在原有右侧吸附栏内，打开浏览器原生侧边面板；独立资料库用于回看和管理，受限页面弹窗提供资料库入口。视频悬浮菜单不放学习入口，普通网页的扩展图标仍打开原设置。
- 原右侧吸附栏保留，不再因语言尚未配置或当前网站属于视频平台而隐藏；主动关闭和站点禁用仍生效，iframe 不重复显示。
- 保存在线媒体的标题、来源、播放位置与当前可读取字幕。
- 本地资料库、不可变字幕版本、字幕片段收藏、带标签的笔记与笔记编辑。
- 清除旧翻译缓存不会删除资料库中的字幕副本、笔记、片段或截图。
- SRT/VTT 导入及导出、Markdown 导出、完整 ZIP 备份与恢复。
- 恢复支持合并、跳过已有资料、替换当前资料库；验证失败会回滚整个事务。

### 第二阶段：理解内容

- 解释概念、拆解逻辑、对比概念。
- 选择 1–10 行字幕，自动包含邻近上下文；每次最多 20 行上下文、24000 字符。
- 资料库批量操作先展示供应商、模型与实际发送内容，确认后才调用 BYOK；实时侧面板使用一次明确的发送按钮，预览可选。两者都不自动发送笔记。
- 视频内容、AI 补充背景、不能确认的内容分开保存。
- 引用只允许来自实际发送的字幕行；时间戳由本地字幕解析，不采信模型生成的时间。
- 专业术语表的新建、编辑和导入入口已从学习页面移除。旧术语数据继续保存在本地和备份中，并兼容既有 AI 字幕翻译缓存逻辑；不再作为主学习流程。
- 保守修复若改变识别出的代码标识符或数值，会保留原字幕。机器翻译及既有失败兜底仍是独立路径，不保证应用专业术语偏好。

### 第三阶段：精读体验

- 资料库搜索标题、当前版本字幕、笔记与概念解释；资料内原文/译文全文搜索。
- 双语、只看原文、按需揭示译文，以及原始字幕与修复字幕对照。
- 选中 1–20 行字幕，通过预览/确认调用 BYOK 翻译；代码标识符和数值缺失时拒绝应用，成功后保存为新版本。
- 读取本地视频或音频，配合导入字幕播放，字幕高亮与本地字幕显示。
- 片段重听按实际媒体时钟结束，不受播放倍速影响；本地播放定期保存进度。已保存在线资料播放时约每 15 秒保存进度，暂停/跳转时补存，重开后可继续定位。

## 如何使用

1. 执行 `npm install`、`npm run build`，在 Chromium 中加载 `dist/`。
2. 更新扩展后刷新已打开的视频页面，让新增脚本生效。
3. 在线学习：点击原有右侧吸附栏中的「学习控制台」，直接输入就能记独立笔记。需要出处时展开「关联出处」，选择网页/选文或当前视频字幕；看视频时可直接勾选字幕作为笔记出处或点击「解释选中字幕」。
4. 本地学习：工作台左侧「打开本地视频 / 音频」。字幕有两个入口：“导入字幕，创建新资料”会建立仅字幕资料；“给当前媒体添加字幕版本：《标题》”把 SRT/VTT 添加到当前视频/音频，媒体及旧字幕版本均保留。
5. 面板中的「资料库」用于回看、搜索与导出。资料库中仍可选中多行字幕、管理术语和执行带预览确认的批量处理。
6. 定期导出完整项目包。API Key 在原 BYOK 设置页单独管理，不在学习项目包中。

新工作台目前为简体中文界面；旧翻译器保留既有语言支持。其他语言的扩展名称/介绍暂使用英文品牌文案。

## 本地保存与网络处理

- 学习资料、字幕、片段、笔记、概念解释、术语和截图保存在扩展自身域的 IndexedDB `ChengLearning` 中。
- API Key 继续保存在 `chrome.storage.local` 的旧 BYOK 配置键；阅读偏好也保存在本机。
- 不引入产品账号、云端资料数据库或自动同步。
- **本地保存不等于离线 AI。** BYOK 会把确认的音频/字幕/问题/匹配术语发给所选服务商，费用及服务端保留政策由供应商决定。
- 术语备注属于请求内容，预览中可见；未匹配术语、其他资料级术语和个人笔记不会自动发送。
- 既有网页翻译、视频字幕翻译与转写按用户原有开关运行。资料库的逐次预览确认与侧面板的明确发送操作都不改变这些既有功能的启动规则。
- 实时笔记草稿暂存在 `chrome.storage.local` 中的 `cheng_study_draft:*` 键，提交后进入 IndexedDB，成功后清理对应日志。资料库备份包含已提交的笔记，不包含尚未提交的临时草稿。
- “画面与截图”的展示和新增入口已移除。已有截图仍保存在本地、完整备份和旧 Markdown 图片包中，不会自动发送给 AI。
- 敏感视频、组会等资料仍须先确认处理授权；该功能不承诺供应商零留存。

## 数据及版本

| 表 | 作用 |
| --- | --- |
| materials | 来源身份、标题、当前字幕版本、播放进度、本地文件关联元数据 |
| transcripts | 原文、保守修复文本、译文及生成来源；每次保存新版本，不覆盖旧版本 |
| clips | 起止时间、字幕快照、字幕版本和行标识 |
| notes | 用户笔记、标签、可选资料片段或网页选文出处；也可完全独立 |
| concepts | 问题、解释分区、字幕引用、上下文行、引擎及模型 |
| glossary | 原词、译法、别名、备注、全局/资料级范围 |
| attachments | 图片、截图时间、说明、可选片段关联 |

Schema 当前版本为 3。v1 数据库会为原笔记补充空出处，v1/v2 的旧片段会标记为“独立保存”；不改变原 ID、正文、时间和关联。v1/v2 项目包可导入并按 v3 校验，导出统一为 v3。其他未知版本会拒绝导入。

原上游云端收藏路由不恢复使用；新的片段与笔记完全独立。旧版 API Key、翻译设置、消息名及本地助手标识保留兼容，不全局重命名 `lexihalo`/`trancy`。

## 项目包

应用导出的无压缩 ZIP，包含：

```text
manifest.json          # 格式、版本、SHA-256 文件校验清单
materials.json
transcripts.json
clips.json
notes.json
concepts.json
glossary.json
attachments.json
attachments/*.png     # 或 jpeg / webp
```

- 不包含 API Key、Cookie、完整本地路径或原视频文件；阅读偏好与旧版翻译器设置目前不随学习项目包迁移。
- 来源链接只保留受支持的身份查询参数，去除临时鉴权参数和跟踪参数；部分分享链接可能需要手动重新打开。
- ZIP 大小上限 128 MB，只接受澄格式、版本和校验有效的无压缩项目包；不接受任意 ZIP、路径穿越、重复文件或压缩炸弹。
- SRT/VTT 文件上限 16 MB、30000 行；CSV/JSON 术语上限 4 MB、5000 条；图片仅 PNG/JPEG/WebP，最大约 9 MB。
- 项目包不加密，请自行妥善保管。SHA-256 校验用于检查损坏，不是发行者签名。
- 本地视频通过 File/Object URL 读取，不复制进 IndexedDB。刷新或重开后临时 Object URL 失效，界面区分“当前已连接”“需要重新连接”“尚未连接”，不会把只剩文件名/指纹的状态称为已关联。重新选择同一文件会通过采样指纹恢复播放；“清除历史关联”只清空文件名/采样指纹和当前 Object URL，字幕版本、播放进度、片段、笔记及电脑上的原文件均保留。
- 关联时使用文件长度及首尾各 1 MB 的采样指纹辅助识别，不是完整文件的加密完整性证明；不同文件需明确确认替换。
- 浏览器卸载扩展、删除配置文件或清除站点数据可能删除资料库；本机保存不能代替备份。

## 平台边界

- 在线资料依赖当前播放器可读取的字幕；没有字幕时仍可使用既有 BYOK 转写或手动导入。
- 标准媒体使用播放器时钟；封闭播放器、DRM、嵌入式跨域播放器可能无法精确定位，不绕过限制。
- 页面只提供临时 `blob:` 且没有稳定单条内容身份时，资料识别仍可能受限制；专门适配平台优先使用平台身份。
- 本地播放取决于浏览器解码能力，推荐常见 MP4/WebM/MP3/WAV；不支持的编码须自行转换。
- 学习库目前整体读取后在本机筛选；超大型资料库的增量索引、虚拟列表和附件流式备份属于后续优化。

## 统一视觉系统

配色统一维护于 `config/themes.json`，构建时由 `tools/theme-system.mjs` 生成扩展页面、Reader 与视频 UI 的设计令牌；`src/styles/cheng-theme.css` 保留基础字体、圆角与品牌样式。浅色默认使用墨绿和纸白，其他主题使用各自可读的背景、文字及强调色。

网页和视频主题设置共享偏好，实时应用于设置预览、侧边悬浮栏、视频菜单、学习侧栏、资料库和扩展设置页；自动模式跟随系统明暗变化。旧配置存在差异时以 Reader 主题为准。只同步公开的 `cheng_theme` 字段，不向网页暴露密钥或完整设置，也不改变宿主网页配色。

新增页面应复用主题令牌，不写死浅色背景。`npm run test:theme` 覆盖全部主题的预览与实际颜色、跨界面同步、重载持久化、系统切换和网页隔离。

图标系统以 `assets/logo.svg` 为单一源：圆角墨绿底代表稳定的本地资料容器，浅色光环呼应“澄”，打开的书页代表学习/笔记，底部水波代表理解逐渐澄明。主扩展图标与 Safari 16–1024px 资源由 `npm run build:icons` 生成；右侧“学习控制台”使用同源的光环/书页线性符号，视频按钮和 Reader 品牌位读取同一套 PNG。`npm run test:icons` 校验尺寸、主题色、功能符号和 `dist/` 哈希一致性。

```text
src/learning/schema.js         数据校验与来源身份
src/learning/store.js          IndexedDB 事务、版本、合并与恢复
src/learning/background.js     受信任消息路由、在线保存及定位
src/learning/ai.js             解释、术语匹配、选中字幕翻译
src/learning/media.js          本地文件关联及旧截图数据兼容
src/learning/transfer.js       字幕/术语格式与 ZIP/Markdown
src/learning/study-background.js 原生侧边面板打开、实时读取、片段与上下文冻结
src/learning/notes.js          通用笔记草稿、独立/可选出处、自动保存与恢复
src/learning/notes-library.js  全部笔记列表、编辑、搜索和 Markdown 导出
src/learning/study.js          自动跟随、实时对照、通用笔记 UI 与片段解释
src/pages/study.html           观看时的侧边学习面板
src/learning/workspace.js      资料库、片段与笔记
src/learning/understanding.js  解释与术语 UI
src/learning/reading.js        搜索、显示模式、本地播放及旧附件兼容
src/content/learning-entry.js  隔离环境中的入口消息桥（不创建悬浮 UI）
src/video/learning-bridge.js   MAIN 环境的只读快照/播放控制
src/pages/workspace.html       独立工作台
config/brand.json              构建时的展示品牌与扩展介绍
```

完整资料读取与恢复在扩展自有页面直接访问 IndexedDB，避免 Chrome 消息体积上限；网页没有这个存储域。网页脚本无法读取资料库。资料库/弹窗与原生学习面板分别验证扩展自身协议、域和页面路径；实时学习 API 不接受普通网页的读取、收藏或解释请求。侧栏入口在原始用户手势中同步请求原生面板，不暴露全量导出、密钥或笔记读取接口。页面快照被当作不可信输入校验，所有文字使用 `textContent` 展示。

构建器仍使用旧 Bundle 基线生成原功能；新工作台按独立文件复制到 `assets/learning/`，后台模块追加到后台 Bundle，最后统一进入 `dist/`。不要直接编辑这些生成文件。

运行时同时存在旧消息信封（`from/to/name/uuid`）与新类型消息（`type: cheng:learning:*`、媒体等）。旧总线的监听器必须先同步检查信封格式，对其他协议返回 `false`，不能先启动 Promise 或直接调用 `to.includes`，否则会抛出后台异常并可能争抢新协议的响应通道。该边界在 background、Reader 和 Video 三个旧监听器中统一处理。
